# 🏦 Bank Management System (C++ OOP)

A console-based **Bank Management System** developed in C++ using Object-Oriented Programming (OOP) concepts. The system handles client and user management, transactions, and system logs stored in text files.

---

## 🌟 Key Features

### 👤 Client Management
* **Show Client List:** Displays all registered clients and their account details.
* **Add New Client:** Creates new accounts with validated data.
* **Delete / Update Client:** Manages existing client records.
* **Find Client:** Quick search functionality by Account Number.

### 💳 Transactions
* **Deposit & Withdraw:** Process dynamic balance updates.
* **Total Balances:** View combined bank total and individual client balances.
* **Transfer:** Direct money transfer between two clients with history logs.

### 🔐 User Management & Security
* **Manage Users:** Add, update, delete, or search system operators.
* **Permission System:** Granular access rights assigned to each user.
* **Login Registers:** Automatic tracking of user logins with timestamps.

---

## 🛠️ Technical Stack & Concepts Used

* **Language:** C++11 / C++17
* **Paradigm:** Object-Oriented Programming (Encapsulation, Inheritance, Polymorphism, Abstraction)
* **Architecture:** Layered Architecture (Screen Display Classes, Controller Classes, Data Management Classes)
* **Data Storage:** Flat Text Files (`Clients.txt`, `Users.txt`, `TransferLog.txt`)
* **IDE:** Microsoft Visual Studio
